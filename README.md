# fun-cli — Terminal Experience Studio

A friendly Linux desktop studio for bringing the command line to life.

## Versions

- v0.1.0 — original Tkinter MVP
- v0.2.0 — animated UI, dashboard, backups browser, AI companion tab
- v1.0.0 — significant upgrade: modular layout, install/uninstall, tests

Each version lives in its own folder with its own README.

To run the latest: cd into v1.0.0 and run ./install.sh
