Everything your terminal shows, in one place

Each page has a live preview. Nothing changes on your system until you press Apply.

Welcome & MOTD

Choose how your terminal greets you. Write a greeting using {user}, {host} and {daypart}, pick one of 24 moods, and add rotating tips, an extra message and an optional Fastfetch summary.

The preview types itself out just like the real thing.

Terminal Appearance

10 theme presets, colours, a 16-colour palette, font, size, cursor shape, opacity and background image. Themes can be exported and imported as small files.

The app tells you plainly when a terminal can't do something, for example GNOME Terminal has no background-image setting.

Prompt Designer

Pick a prompt style with a live preview that shows both a normal command and a failed one.

Minimal, Classic and Two-line work in plain Bash with nothing to install. Two more styles use Starship if you have it.

ASCII Art Studio

Start from the built-in gallery, or turn any picture into text art with live controls for width, contrast, brightness, invert and character style.

Conversion happens on your computer, and the art can appear above your greeting when a terminal opens.

AI Companion

Everything works offline: built-in tips and a command explainer that warns you about risky commands such as rm -rf /.

If you like, connect Groq, OpenAI, OpenRouter or a local Ollama to write greetings in a personality you choose. Greetings are saved to a plain file, so opening a terminal never waits on the internet.

Backups & Recovery

Restore any backup, remove everything the app added, switch between dark and light mode, or turn off animations.

Use Ctrl+1 to Ctrl+7 to jump between pages.

Careful with your shell

Changing a shell's startup file is a little risky, so the app is built to be careful.

Backup firstEvery change creates a timestamped backup, and every apply has an Undo.
Only our section~/.bashrc is edited only between marker lines. If the markers are damaged, the app stops and changes nothing.
Safe writesFiles are written atomically and symlinks are respected, so dotfile managers keep working.
No admin rightsNothing needs sudo. Only interactive shells are affected.
Fast and offline at startupOpening a terminal makes no network calls.
Text can't run codeAnything you type is quoted and stripped of control characters. Git branch names in the prompt are filtered too.
Your Starship config is safeThe app uses its own config file and never overwrites yours.
Keys stay privateAPI keys are never written to settings or shell files. They live in memory, or in your desktop keyring if you switch that on.

Undoing by hand: the app only touches the lines between # >>> Terminal Experience Studio >>> and # <<< Terminal Experience Studio <<<, plus an optional second block ending in : prompt. Backups are in ~/.local/share/terminal-experience-studio/backups/.

Install and get started

Requires a GNOME-based Linux desktop (built for Zorin OS 18 / Ubuntu 24.04), Python 3.10 or newer, and Bash.

  1. Install dependencies

    Usually already installed on Zorin OS.

    sudo apt install python3-gi gir1.2-gtk-4.0 gir1.2-adw-1 librsvg2-common

  2. Get the app

    git clone https://github.com/AbduLz0/fun-cli.git cd fun-cli

  3. Run it

    Try it straight from the folder, or install it for your user (menu entry and launcher, no sudo).

    ./run.sh # or ./install.sh

  4. Apply your first change

    Open Welcome & MOTD, pick a mood and write a greeting. Press Apply to Bash and confirm. A backup is made first. Open a new terminal to see the result. Changed your mind? Press Undo.

    For terminal colours and fonts, open Terminal Appearance, choose your terminal and press Apply theme.

Optional extras

  • starship for the Starship prompts
  • fastfetch for the system summary
  • libsecret-tools to keep API keys in your desktop keyring

Known limits

  • Bash only. Zsh and Fish are not implemented yet.
  • Konsole needs one manual step: choose the "Terminal Experience Studio" profile from its Settings menu.
  • Starship styles only take effect once Starship is installed.
  • AI is called only when you press a button, never when a terminal starts.
