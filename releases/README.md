# Archived Releases

This directory contains historical versions of fun-cli. The current version
(v1.0.0 and later) lives at the repository root.

- [v0.1.0](v0.1.0/) — original Tkinter MVP
- [v0.2.0](v0.2.0/) — animated UI, dashboard, and AI companion prototype

These folders preserve the source for each historical version. GitHub Releases
and Git tags are managed separately; do not create historical tags against the
current commit unless those tags point to the correct historical snapshots.
