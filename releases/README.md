# Fun-CLI Historical Releases

This folder contains the older, standalone versions of the Terminal Experience Studio. 
These are kept for historical reference and users who may be running older systems.

## Versions

- **[v0.1.0](./v0.1.0)** - The original Tkinter MVP. 
- **[v0.2.0](./v0.2.0)** - Animated UI, dashboard, backups browser, and AI companion tab.

*Note: These versions are no longer maintained. For the latest features, safety updates, and GTK4 interface, please use the main branch (v1.0.0).*
